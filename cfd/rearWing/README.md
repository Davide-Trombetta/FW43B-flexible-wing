# FW43B rear wing — automated OpenFOAM v2306 workflow

Steady RANS (k-ω SST, `simpleFoam`) of the isolated Williams FW43B rear wing,
from the STL of one flap angle to the PDF reports, with OpenFOAM **v2306**
(ESI, openfoam.com). The pressure on the wing (`walls.vtk`) is the input of
the structural load transfer (`fsi/map_pressure.py`).

The workflow is derived from our Ahmed-body case (OpenFOAM-14, openfoam.org):
same structure and scripts, ported to the ESI syntax and adapted to the wing.

- **Two commands**: `./Allrun.pre -angle <deg>` (mesh) and `./Allrun -speed <U>` (run).
- **No magic numbers**: the values chosen by hand are in `system/meshParameters`
  and `constant/caseSettings`; everything else is computed by `scripts/` and
  written in `system/meshVariables`.
- **Grid study**: the same case gives three meshes, S, M and L, with the same
  wall layers and a refinement ratio of 1.3 (GCI).
- **Quality control**: a bad mesh stops the workflow, a failed run is
  detected, and every run records its inputs, environment and results
  (`report/results/summary.csv`: one line per run, flap angle and speed included).

## 1. Structure

```
cfd/rearWing/
├── Allrun.pre              mesh: STL of the angle → design scripts → blockMesh → snappyHexMesh → checks → mesh report
├── Allrun                  run: potentialFoam → simpleFoam → convergence stop → checks → results report
├── Allclean                removes everything that is generated (mesh, results, logs, reports)
├── 0.orig/                 initial and boundary conditions (U, p, k, omega, epsilon, nut; Phi for potentialFoam)
├── constant/
│   ├── caseSettings        flow and run settings chosen by hand
│   ├── turbulenceProperties RAS model, from caseSettings (turbulenceModel)
│   ├── transportProperties kinematic viscosity
│   └── triSurface/         rearWing.stl, copied by Allrun.pre -angle (not versioned)
├── system/
│   ├── meshParameters      mesh and flow values chosen by hand
│   ├── meshVariables       GENERATED by scripts/ — do not edit
│   ├── controlDict  fvSchemes  fvSolution  decomposeParDict
│   ├── blockMeshDict  snappyHexMeshDict  surfaceFeatureExtractDict  meshQualityDict
│   ├── functions           function objects run with the solver (included by controlDict)
│   ├── reportFunctions     function objects of the results report (run after the solver)
│   └── Cp Cp0 forces forceCoeffs inletPressure profiles solverInfo wingSurfaces
│       planes isoSurfaces noseStreamlines wakeStreamlines
├── scripts/                bash: mesh design, checks, convergence, reports
└── tools/                  C++ / Python / awk tools used by the scripts
```

Generated and not versioned: `0/`, `processor*/`, `constant/polyMesh/`,
`postProcessing/`, `logs/`, `report/`, `system/meshVariables`,
`system/stlRegions`, `system/regionForces`, `system/reportGeometry`,
`system/rearRegions`, `constant/triSurface/rearWing.stl`, `*.eMesh`,
`tools/bin/`.

### 1.1 Scripts

| Script | Role |
|---|---|
| `functions` | Shared helpers: read `meshParameters`/`meshVariables`, write values (`setLine`, with `sed`: keeps the comments), histories of the function objects by column name. |
| `geometryInfo` | Checks the STL (`surfaceCheck`), measures sizes, wetted, frontal and planform areas (`tools/stlInfo`); writes `system/stlRegions` (one wall patch per STL region) and `system/regionForces` (one `forces` function per region). |
| `boundaryLayer [S\|M\|L]` | Near-wall design from y+: first layer, stack, last layer, **surface cell** of the size. |
| `backgroundMesh` | Domain and background mesh, surface level, blockage check. |
| `snappySetup` | Near and wake boxes (levels: `nearLevelDrop`, `wakeLevelDrop`), layers, snap iterations, `locationInMesh`. |
| `rearRefinement` | Ahmed-body slant refinement (`rearRefinement no` for the wing). |
| `postSetup` | Wing section (`sectionY`), wake profiles, report planes and streamline seeds. |
| `checkCells <nCores>` | Estimated number of cells; stops if above `maxGlobalCells` or 15 M cells every 8 cores. |
| `convergenceMonitor` | Started by `Allrun`: stops the run when the mean Cd and Cl are converged (MSER, standard errors and drifts within `cdTolerance`). |
| `history <function> <file> [columns]` | History of a function object over every restart folder; columns taken **by name**. |
| `report mesh\|results` | PDF reports, `metadata.yaml`, `summary.csv`. |

### 1.2 Tools

| Tool | Role |
|---|---|
| `stlInfo/stlInfo.cpp` | Plain C++17 (no OpenFOAM library): sizes and areas of each STL region. Built by `Allrun.pre` (cmake). |
| `readSets.py` | Merges the files of one sampled line (`profiles`) into one table, whatever the OpenFOAM version. |
| `mser.awk` | MSER start of the stable part, standard error with batch means, drift test. |
| `viewMesh.py`, `report/images.py`, `report/plots.py` | ParaView (`pvbatch`): mesh images, result images, charts. |
| `rearSurface.py` | Used only by `rearRefinement` (Ahmed body). |

## 2. Requirements

OpenFOAM v2306 (`source /usr/lib/openfoam/openfoam2306/etc/bashrc` or your
installation), Open MPI, cmake and g++ (for `stlInfo`), Python 3.
Optional: ParaView `pvbatch` (images) and LaTeX with siunitx, booktabs, float
(PDF). Without them the workflow still runs; the reports are written without
images, or as `.tex` without PDF.

Run the case on the Linux filesystem of WSL (e.g. `$FOAM_RUN`), not under `/mnt/c`.

## 3. Running

```bash
source /usr/lib/openfoam/openfoam2306/etc/bashrc
cd cfd/rearWing                      # or a copy: then set GEOMETRY_DIR
./Allrun.pre -angle 0 -mesh S -cores 8
./Allrun -speed 70
```

`Allrun.pre` options: `-a|-angle -4|-2|0|+2|+4` (copies
`$GEOMETRY_DIR/FW43B_rearWing_flap_<deg>deg.stl`, default `../../geometry`),
`-m|-mesh S|M|L`, `-c|-cores N`.
`Allrun` options: `-s|-speed U` (writes `uInf` in `system/meshParameters`),
`-continue` (goes on from the latest time).

A case copied elsewhere (e.g. to `$FOAM_RUN`):

```bash
cp -r cfd/rearWing $FOAM_RUN/rw_0deg_S
cd $FOAM_RUN/rw_0deg_S
GEOMETRY_DIR=/path/to/FW43B-flexible-wing/geometry ./Allrun.pre -angle 0
```

Follow the solver with `tail -f log.simpleFoam`, the convergence with
`tail -f log.convergence` (both moved to `logs/` at the end).

### Outputs

| File | Contents |
|---|---|
| `report/mesh/mesh.pdf` | design values, snappyHexMesh steps, checkMesh, layers per patch, mesh images |
| `report/results/results.pdf` | Cd, Cl (mean, standard error, σ); drag, downforce, efficiency E = L/D; forces of each part of the wing; convergence; y+ per patch; Cp, Cf, sections, streamlines, iso-surfaces, planes |
| `report/results/summary.csv` | one line: flap angle, speed, mesh, cells, Cd, Cl, drag, downforce, efficiency, residuals, git commit |
| `postProcessing/wingSurfaces/<time>/walls.vtk` | wall pressure (kinematic `p`) for `fsi/map_pressure.py` |

Load transfer to the structure (from the repository root):

```bash
python3 fsi/map_pressure.py structure/flap_0deg/ansys/rw_shell_medium_apdl.inp \
        cfd/rearWing/postProcessing/wingSurfaces/<time>/walls.vtk \
        -o structure/flap_0deg/ansys/loads_pressure_apdl.inp
```

## 4. Mesh sizes

Near-wall treatment: **wall functions** (k-ω SST), target y+ = 100 at the first cell
centre at 70 m/s (`uInf` of the mesh design). The same wall layers are used for every
size (`system/meshParameters`, `scripts/boundaryLayer`):

| Layers | First layer | Growth | Last layer | Stack |
|---|---|---|---|---|
| 4 | 1.08 mm | 1.2 | 1.86 mm | 5.78 mm |

Only `finalLayerThickness` changes between sizes, and with it the surface cell
(`surface cell = last layer / finalLayerThickness`). The refinement levels are fixed by
mesh S, so every region of the mesh is scaled by the same factor: the refinement ratio
between two sizes is r = 1.4 (cells × r³ ≈ 2.7), as required for the GCI study.

| Size | finalLayerThickness | Surface cell | Cells | Use |
|---|---|---|---|---|
| XS | 0.236 | 7.9 mm | ≈ 0.8 M (estimate) | grid study (GCI) |
| S  | 0.33  | 5.6 mm | 2.15 M (obtained; estimate 2.33 M) | production runs |
| M  | 0.462 | 4.0 mm | ≈ 5.9 M (estimate) | grid study (GCI) |

The near box is 4 times, the wake box 8 times coarser than the surface
(`nearLevelDrop 2`, `wakeLevelDrop 3`); the mainplane, the flap, the DRS pod and the
pylons get one more level within `flapRefineCells` surface cells of the flap, so that
the 10 mm slot holds a few cells besides the layers.
