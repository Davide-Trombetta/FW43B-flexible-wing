# FW43B rear wing — automated OpenFOAM v2306 workflow (URANS)

Unsteady RANS (k-ω SST, `pimpleFoam`) of the isolated Williams FW43B rear wing,
from the STL of one flap angle to the PDF reports, with OpenFOAM **v2306**
(ESI, openfoam.com). The flow behind the flap is unsteady, so the run lasts a
fixed time and the results are **time averages**; the mean wall pressure
(`pMean` in `walls.vtk`) is the input of the structural load transfer
(`fsi/map_pressure.py`).

This case is the URANS version of `cfd/rearWing` (steady, `simpleFoam`): same
mesh, scripts and reports; only the solver settings, the time averaging and the
results report change. The workflow is derived from our Ahmed-body case
(OpenFOAM-14, openfoam.org), ported to the ESI syntax and adapted to the wing.

- **Two commands**: `./Allrun.pre -angle <deg>` (mesh) and `./Allrun -speed <U>` (run).
- **No magic numbers**: the values chosen by hand are in `system/meshParameters`
  and `constant/caseSettings`; everything else is computed by `scripts/` and
  written in `system/meshVariables`.
- **Speed-independent time settings**: time step, end time and start of the
  averaging are given at 70 m/s and scaled by `70 / uInf`, so every speed has
  the same Courant number and the same number of flow-through times.
- **Grid study**: the same case gives the meshes XS, S and M, with the same
  wall layers and a refinement ratio of 1.4 (GCI).
- **Quality control**: a bad mesh stops the workflow, a failed run is
  detected, and every run records its inputs, environment and results
  (`report/results/summary.csv`: one line per run, flap angle and speed included).

## 1. Structure

```
cfd/rearWingURANS/
├── Allrun.pre              mesh: STL of the angle → design scripts → blockMesh → snappyHexMesh → checks → mesh report
├── Allrun                  run: potentialFoam → pimpleFoam (to endTime) → checks → results report
├── Allclean                removes everything that is generated (mesh, results, logs, reports)
├── 0.orig/                 initial and boundary conditions (U, p, k, omega, epsilon, nut; Phi for potentialFoam)
├── constant/
│   ├── caseSettings        flow and run settings chosen by hand
│   ├── turbulenceProperties RAS model, from caseSettings (turbulenceModel)
│   ├── transportProperties kinematic viscosity
│   └── triSurface/         rearWing.stl, copied by Allrun.pre -angle (not versioned)
├── system/
│   ├── meshParameters      mesh and flow values chosen by hand
│   ├── meshVariables       GENERATED by scripts/ — do not edit
│   ├── controlDict         pimpleFoam, fixed time step, endTime (scaled with uInf)
│   ├── fvSchemes  fvSolution  decomposeParDict
│   ├── blockMeshDict  snappyHexMeshDict  surfaceFeatureExtractDict  meshQualityDict
│   ├── functions           function objects run with the solver (included by controlDict)
│   ├── fieldAverage        time averages UMean, pMean, kMean (+ UPrime2Mean, pPrime2Mean)
│   ├── reportFunctions     function objects of the results report (run after the solver)
│   └── Cp Cp0 CpMean Cp0Mean QMean readMean forces forceCoeffs inletPressure
│       profiles solverInfo wingSurfaces planes isoSurfaces noseStreamlines wakeStreamlines
├── scripts/                bash: mesh design, checks, reports
└── tools/                  C++ / Python / awk tools used by the scripts
```

Generated and not versioned: `0/`, `processor*/`, `constant/polyMesh/`,
`postProcessing/`, `logs/`, `report/`, `system/meshVariables`,
`system/stlRegions`, `system/regionForces`, `system/reportGeometry`,
`system/rearRegions`, `constant/triSurface/rearWing.stl`, `*.eMesh`,
`tools/bin/`.

### 1.1 Scripts

| Script | Role |
|---|---|
| `functions` | Shared helpers: read `meshParameters`/`meshVariables`, write values (`setLine`, with `sed`: keeps the comments), histories of the function objects by column name. |
| `geometryInfo` | Checks the STL (`surfaceCheck`), measures sizes, wetted, frontal and planform areas (`tools/stlInfo`); writes `system/stlRegions` (one wall patch per STL region) and `system/regionForces` (one `forces` function per region). |
| `boundaryLayer [XS\|S\|M\|L]` | Near-wall design from y+: first layer, stack, last layer, **surface cell** of the size. |
| `backgroundMesh` | Domain and background mesh, surface level, blockage check. |
| `snappySetup` | Near and wake boxes (levels: `nearLevelDrop`, `wakeLevelDrop`), layers, snap iterations, `locationInMesh`. |
| `rearRefinement` | Ahmed-body slant refinement (`rearRefinement no` for the wing). |
| `postSetup` | Wing section (`sectionY`), wake profiles, report planes and streamline seeds (the wake seeds around the endplate tips, for the tip vortices). |
| `checkCells <nCores>` | Estimated number of cells; stops if above `maxGlobalCells` or 15 M cells every 8 cores. |
| `convergenceMonitor` | Steady case only (`simpleFoam`): not started by `Allrun` for `pimpleFoam`, which always runs to `endTime`. |
| `history <function> <file> [columns]` | History of a function object over every restart folder; columns taken **by name**. |
| `report mesh\|results` | PDF reports, `metadata.yaml`, `summary.csv`. |

### 1.2 Tools

| Tool | Role |
|---|---|
| `stlInfo/stlInfo.cpp` | Plain C++17 (no OpenFOAM library): sizes and areas of each STL region. Built by `Allrun.pre` (cmake). |
| `readSets.py` | Merges the files of one sampled line (`profiles`) into one table, whatever the OpenFOAM version. |
| `mser.awk` | MSER end of the start-up transient (used as a check of the averaging window), standard error with batch means, drift test. |
| `report/spectrum.py` | Amplitude spectrum of Cd and Cl over the averaging window (Hann window): frequency, Strouhal number and amplitude of the strongest peak. |
| `viewMesh.py`, `report/images.py`, `report/plots.py` | ParaView (`pvbatch`): mesh images, result images (mean fields), charts. |
| `rearSurface.py` | Used only by `rearRefinement` (Ahmed body). |

## 2. Requirements

OpenFOAM v2306 (`source /usr/lib/openfoam/openfoam2306/etc/bashrc` or your
installation), Open MPI, cmake and g++ (for `stlInfo`), Python 3.
Optional: ParaView `pvbatch` (images) and LaTeX with siunitx, booktabs, float
(PDF). Without them the workflow still runs; the reports are written without
images, or as `.tex` without PDF.

Run the case on the Linux filesystem of WSL (e.g. `$FOAM_RUN`), not under `/mnt/c`.

## 3. Running

```bash
source /usr/lib/openfoam/openfoam2306/etc/bashrc
cd cfd/rearWingURANS                 # or a copy: then set GEOMETRY_DIR
./Allrun.pre -angle 0 -mesh S -cores 7
./Allrun -speed 70
```

`Allrun.pre` options: `-a|-angle -4|-2|0|+2|+4` (copies
`$GEOMETRY_DIR/FW43B_rearWing_flap_<deg>deg.stl`, default `../../geometry`),
`-m|-mesh XS|S|M|L`, `-c|-cores N`.
`Allrun` options: `-s|-speed U` (writes `uInf` in `system/meshParameters`; a new
run), `-continue` (goes on from the latest time written, e.g. after a stop or a
crash; potentialFoam is not run again and the time averages continue).

A case copied elsewhere (e.g. to `$FOAM_RUN`):

```bash
cp -r cfd/rearWingURANS $FOAM_RUN/rw_0deg_S
cd $FOAM_RUN/rw_0deg_S
GEOMETRY_DIR=/path/to/FW43B-flexible-wing/geometry ./Allrun.pre -angle 0
```

Follow the solver with `tail -f log.pimpleFoam` (moved to `logs/` at the end).

### 3.1 What a run does

1. **Initial field**: `potentialFoam -writep -writephi` (new runs only).
2. **pimpleFoam to `endTime`** with a fixed time step (every step costs the same
   work). At 70 m/s: Δt = 2.5 × 10⁻⁴ s, `endTime` = 0.3 s (1200 steps), fields
   written every 200 steps (0.05 s), last two kept (`purgeWrite 2`).
3. **Time averages** (`system/fieldAverage`) from `timeStart` = 0.1 s: `UMean`,
   `pMean`, `kMean` and the fluctuations `UPrime2Mean`, `pPrime2Mean`. The start-up
   transient from the potential flow is left out; the MSER test of the report
   checks that it has ended before `timeStart`.
4. **Checks**: errors and NaN in the last part of `log.pimpleFoam`, the end of the
   run reached, the force outputs written.
5. **Results report** from the mean fields.

All the times above are given at 70 m/s and scaled by `70 / uInf`
(`controlDict`, `fieldAverage`, `CpMean`, `Cp0Mean`).

### 3.2 Solver settings

| | |
|---|---|
| PIMPLE | 3 outer correctors, 2 pressure correctors, 1 non-orthogonal corrector; turbulence solved on the final outer iteration only |
| Relaxation | U 0.7 on the non-final outer iterations, 1 on the final one |
| Final solvers | `relTol 0` (`pFinal`, `UFinal`, `kFinal`, `omegaFinal`) |
| Time scheme | Euler |
| Convection | `linearUpwindV` for U; `upwind` for k and ω (bounded) |
| Courant number | mean ≈ 0.06; local maximum ≈ 110–150 in the thin layer cells: stable with the outer correctors |

Cost on mesh S (2.15 M cells, 7 cores): about 19 s per time step, about 6.5 h
for the 1200 steps at 70 m/s.

### Outputs

| File | Contents |
|---|---|
| `report/mesh/mesh.pdf` | design values, snappyHexMesh steps, checkMesh, layers per patch, mesh images |
| `report/results/results.pdf` | Cd, Cl (time mean, standard error with batch means, σ); drag, downforce, efficiency E = L/D; forces of each part of the wing; histories and averaging window; wake shedding (spectrum, Strouhal number); y+ per patch; mean Cp, Cf, sections, streamlines, Q-criterion, planes |
| `report/results/summary.csv` | one line: flap angle, speed, mesh, cells, solver, time steps, Δt, Cd, Cl (mean and σ), drag, downforce, efficiency, shedding frequency, Strouhal number, git commit |
| `postProcessing/wingSurfaces/<time>/walls.vtk` | wall pressure, instantaneous `p` and time-averaged `pMean` (kinematic), for `fsi/map_pressure.py` |

Load transfer to the structure (from the repository root), with the **mean**
pressure:

```bash
python3 fsi/map_pressure.py structure/flap_0deg/ansys/rw_shell_medium_apdl.inp \
        cfd/rearWingURANS/postProcessing/wingSurfaces/<time>/walls.vtk \
        --field pMean \
        -o structure/flap_0deg/ansys/loads_pressure_apdl.inp
```

Use the last time written (`<time>` = `endTime`): its `pMean` is the average over
the whole window.

## 4. Mesh sizes

Near-wall treatment: **wall functions** (k-ω SST), target y+ = 100 at the first cell
centre at 70 m/s (`uInf` of the mesh design). The same wall layers are used for every
size (`system/meshParameters`, `scripts/boundaryLayer`):

| Layers | First layer | Growth | Last layer | Stack |
|---|---|---|---|---|
| 4 | 1.08 mm | 1.2 | 1.86 mm | 5.78 mm |

Only `finalLayerThickness` changes between sizes, and with it the surface cell
(`surface cell = last layer / finalLayerThickness`). The refinement levels are fixed by
mesh S, so every region of the mesh is scaled by the same factor: the refinement ratio
between two sizes is r = 1.4 (cells × r³ ≈ 2.7), as required for the GCI study.

| Size | finalLayerThickness | Surface cell | Cells | Use |
|---|---|---|---|---|
| XS | 0.236 | 7.9 mm | ≈ 0.8 M (estimate) | grid study (GCI) |
| S  | 0.33  | 5.6 mm | 2.15 M (obtained; estimate 2.33 M) | production runs |
| M  | 0.462 | 4.0 mm | ≈ 5.9 M (estimate) | grid study (GCI) |

The near box is 4 times, the wake box 8 times coarser than the surface
(`nearLevelDrop 2`, `wakeLevelDrop 3`); the mainplane, the flap, the DRS pod and the
pylons get one more level within `flapRefineCells` surface cells of the flap, so that
the 10 mm slot holds a few cells besides the layers.

The time step is the same for every size, so the local Courant number grows on the
finer meshes (about × 1.4 from one size to the next): check `Courant Number mean/max`
in `log.pimpleFoam` on mesh M.
